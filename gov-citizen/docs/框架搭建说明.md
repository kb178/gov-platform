# gov-citizen 前端框架搭建说明

## 一、项目概述

**项目名称**：gov-citizen（政务一体化平台 - 老百姓端）

**技术栈**：
- Vue 3.3+ (Composition API)
- Vite 5.0+ (构建工具)
- Element Plus 2.4+ (UI组件库)
- Vue Router 4.2+ (路由管理)
- Pinia 2.1+ (状态管理)
- Axios 1.6+ (HTTP请求)
- Sass (CSS预处理器)

## 三、核心配置说明

### 3.1 Vite 配置 (vite.config.js)

```javascript
// 主要配置项：
1. 路径别名：@ → src 目录
2. 开发服务器代理：/api → http://localhost:8080
3. 自动导入：Element Plus 组件自动导入
4. Sass 全局变量：自动注入 _variables.scss
```

### 3.2 Axios 封装 (api/index.js)

```javascript
// 功能：
1. 请求拦截器：自动添加 Authorization Token
2. 响应拦截器：统一处理错误码
3. Token 过期：自动跳转登录页
4. HTTP 错误：统一提示消息
```

### 3.3 路由配置 (router/index.js)

```javascript
// 功能：
1. 路由懒加载：按需加载页面组件
2. 路由守卫：自动设置页面标题
3. 基础路由：首页、登录、404
```

### 3.4 状态管理 (stores/user.js)

```javascript
// 功能：
1. Token 管理：存储、获取、清除
2. 用户信息：获取、存储
3. 登录状态：计算属性判断
4. 登录/登出：API 调用 + 状态更新
```

## 七、注意事项

1. **组件命名**：使用 PascalCase（如 `DefaultLayout.vue`）
2. **文件命名**：使用 kebab-case（如 `user-store.js`）
3. **CSS 方案**：使用 Scoped SCSS，避免样式污染
4. **API 接口**：统一在 `api/` 目录下定义
5. **状态管理**：全局状态使用 Pinia，局部状态使用 `ref/reactive`
