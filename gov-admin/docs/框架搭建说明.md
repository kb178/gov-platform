# gov-admin 管理员端框架搭建说明

## 一、项目概述

**项目名称**：gov-admin（政务一体化平台 - 管理员端）

**技术栈**：
- Vue 3.3+ (Composition API)
- Vite 5.0+ (构建工具)
- Element Plus 2.4+ (UI组件库)
- Vue Router 4.2+ (路由管理)
- Pinia 2.1+ (状态管理)
- Axios 1.6+ (HTTP请求)
- ECharts 5.4+ (数据可视化)
- Sass (CSS预处理器)

## 三、与 gov-citizen 的区别

| 对比项 | gov-citizen（群众端） | gov-admin（管理员端） |
|--------|----------------------|----------------------|
| 用户 | 老百姓 | 政府工作人员 |
| 布局 | 顶部导航 + 内容区 | 左侧菜单 + 顶部导航 |
| 端口 | 3000 | 3001 |
| Token Key | token | admin_token |
| 特有依赖 | - | ECharts（数据可视化） |
| 权限 | 基础登录 | 角色 + 权限控制 |

## 八、注意事项

1. **Token 存储**：使用 `admin_token` 作为 key，与群众端区分
2. **权限控制**：使用 `hasPermission()` 和 `hasRole()` 方法
3. **菜单折叠**：左侧菜单支持折叠，状态保存在组件内
4. **端口冲突**：开发服务器端口为 3001，群众端为 3000
5. **ECharts**：已添加依赖，数据大屏页面使用
