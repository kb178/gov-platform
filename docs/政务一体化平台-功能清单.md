# 政务一体化平台 - 功能清单

> 海口政务服务微服务项目，类似"海易办"的简化版

---

## 项目目标

搭建一个政务一体化平台，实现老百姓网上办事、工作人员在线审批、电子证照管理等功能。

## 详细功能清单

### 1. 用户服务（认证中心）

**老百姓端：**
- [ ] 手机号注册
- [ ] 密码登录
- [ ] 验证码登录
- [ ] 实名认证（身份证 + 姓名）
- [ ] 个人信息修改
- [ ] 修改密码
- [ ] 找回密码

**工作人员端：**
- [ ] 管理员创建账号
- [ ] 角色分配（局长/科员/窗口人员）
- [ ] 部门绑定
- [ ] 账号启用/禁用

**技术要点：**
- Spring Security + JWT
- OAuth2（微信/支付宝登录）
- Redis 缓存登录状态

---

### 2. 事项服务（办事指南）

**管理员配置：**
- [ ] 事项分类管理（户籍、社保、工商、公积金...）
- [ ] 事项新增/编辑/删除/启用/禁用
- [ ] 办事指南编辑（办理条件、所需材料、办理流程）
- [ ] 表单模板设计（动态表单，JSON Schema）
- [ ] 材料清单配置

**老百姓使用：**
- [ ] 按分类浏览事项
- [ ] 搜索事项
- [ ] 查看办事指南
- [ ] 在线填写申请表
- [ ] 上传材料附件

**技术要点：**
- MyBatis-Plus
- 动态表单（JSON Schema）
- 文件上传（MinIO）

---

### 3. 审批服务（工作流）⭐ 核心

**流程配置：**
- [ ] 审批流程设计（BPMN 画流程图）
- [ ] 流程节点配置（谁来审批、审批规则）
- [ ] 流程版本管理

**审批流转：**
- [ ] 提交申请（老百姓发起）
- [ ] 窗口受理（工作人员确认材料）
- [ ] 科员审核
- [ ] 领导审批
- [ ] 审批通过/驳回（附带意见）
- [ ] 办结归档

**进度查询：**
- [ ] 老百姓查看办件进度
- [ ] 办件状态流转记录
- [ ] 加急催办
- [ ] 超时预警提醒

**技术要点：**
- Flowable 工作流引擎
- BPMN 流程定义
- 任务自动分配

---

### 4. 证照服务

**证照管理：**
- [ ] 证照模板管理（营业执照、居住证模板）
- [ ] 证照字段配置

**证照业务：**
- [ ] 审批通过后自动生成证照（PDF）
- [ ] 证照下发到"我的证照"
- [ ] 证照下载
- [ ] 证照验证（扫码验证真伪）
- [ ] 证照到期提醒

**技术要点：**
- iText/PDFBox（PDF生成）
- 二维码生成
- MinIO 文件存储

---

### 5. 消息服务

**通知方式：**
- [ ] 短信通知（阿里云/腾讯云短信）

## 技术栈

### 后端

| 组件 | 选型 | 说明 |
|------|------|------|
| 注册/配置中心 | Nacos | 服务注册 + 配置管理 |
| 服务网关 | Spring Cloud Gateway | 统一入口 |
| 服务调用 | OpenFeign | 声明式 HTTP 调用 |
| 流程引擎 | Flowable | 审批工作流 |
| 缓存 | Redis | 会话、热点数据 |
| 消息队列 | RabbitMQ | 异步通知、解耦 |
| 数据库 | MySQL + MyBatis-Plus | 持久层 |
| 搜索引擎 | Elasticsearch | 数据分析 |
| 文件存储 | MinIO | 证照、材料存储 |
| 链路追踪 | SkyWalking | 监控排查 |
| 接口文档 | Knife4j | API 文档 |
| 容器化 | Docker | 部署打包 |

### 前端

| 组件 | 选型 | 说明 |
|------|------|------|
| 框架 | Vue3 | 组合式 API |
| 构建工具 | Vite | 快速启动 |
| UI 组件库 | Element Plus | 表格、表单、弹窗 |
| 路由 | Vue Router | 页面跳转 |
| 状态管理 | Pinia | 用户信息、权限 |
| HTTP 请求 | Axios | 调后端接口 |
| 图表 | ECharts | 数据大屏、统计图 |
| 流程设计器 | bpmn.js | 审批流程可视化 |
