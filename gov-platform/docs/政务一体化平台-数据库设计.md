## 表关系图

### 第一阶段表关系（用户权限体系）

```
┌─────────────────────────────────────────────────────────────────┐
│                         用户权限体系                              │
└─────────────────────────────────────────────────────────────────┘

                    ┌──────────────┐
                    │   sys_dept   │
                    │   (部门表)    │
                    └──────┬───────┘
                           │ 1
                           │
                           │ N
                    ┌──────┴───────┐        ┌──────────────┐
                    │   sys_user   │───N:N──│   sys_role   │
                    │   (用户表)    │ user_role│   (角色表)    │
                    └──────────────┘        └──────┬───────┘
                           │                       │
                           │                       │ N:N
                           │                       │ role_menu
                           │                       │
                           │                       │ N
                           │                ┌──────┴───────┐
                           │                │   sys_menu   │
                           │                │   (菜单表)    │
                           │                └──────────────┘
                           │
                           │
                    ┌──────┴───────┐        ┌──────────────┐
                    │  sys_oper_log│        │  sys_login_log│
                    │  (操作日志)   │        │  (登录日志)    │
                    └──────────────┘        └──────────────┘


                    ┌──────────────┐        ┌──────────────┐
                    │  dict_type   │───1:N──│  dict_data   │
                    │ (字典类型表)  │        │  (字典数据表)  │
                    └──────────────┘        └──────────────┘
```

### 表关系说明

| 关系 | 说明 |
|------|------|
| sys_dept → sys_user | 一个部门有多个用户（1:N） |
| sys_user ↔ sys_role | 用户和角色多对多（N:N），通过 user_role 关联 |
| sys_role ↔ sys_menu | 角色和菜单多对多（N:N），通过 role_menu 关联 |
| dict_type → dict_data | 一个字典类型有多个字典数据（1:N） |
| sys_user → sys_oper_log | 一个用户有多条操作日志（1:N） |
| sys_user → sys_login_log | 一个用户有多条登录日志（1:N） |

## 第一阶段表详细设计（共 11 张表）

### 1. sys_user（用户表）

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| user_id | BIGINT | 是 | - | 用户ID（主键） |
| username | VARCHAR(64) | 是 | - | 用户名（唯一） |
| password | VARCHAR(128) | 是 | - | 密码（BCrypt加密） |
| nickname | VARCHAR(64) | 否 | '' | 昵称 |
| real_name | VARCHAR(64) | 否 | '' | 真实姓名 |
| id_card | VARCHAR(18) | 否 | '' | 身份证号 |
| phone | VARCHAR(20) | 否 | '' | 手机号 |
| email | VARCHAR(128) | 否 | '' | 邮箱 |
| sex | TINYINT | 否 | 0 | 性别（0未知 1男 2女） |
| avatar | VARCHAR(255) | 否 | '' | 头像地址 |
| user_type | TINYINT | 否 | 1 | 用户类型（1老百姓 2工作人员） |
| dept_id | BIGINT | 否 | NULL | 部门ID |
| status | TINYINT | 否 | 0 | 状态（0正常 1停用） |
| real_name_status | TINYINT | 否 | 0 | 实名认证状态（0未认证 1已认证） |
| login_ip | VARCHAR(128) | 否 | '' | 最后登录IP |
| login_time | DATETIME | 否 | NULL | 最后登录时间 |
| create_by | VARCHAR(64) | 否 | '' | 创建者 |
| create_time | DATETIME | 否 | CURRENT_TIMESTAMP | 创建时间 |
| update_by | VARCHAR(64) | 否 | '' | 更新者 |
| update_time | DATETIME | 否 | CURRENT_TIMESTAMP | 更新时间 |
| del_flag | TINYINT | 否 | 0 | 删除标志（0存在 1删除） |
| remark | VARCHAR(500) | 否 | '' | 备注 |

**索引：**
- 主键：user_id
