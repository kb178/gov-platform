# 问题记录

> 记录开发过程中遇到的问题及解决方案

---

| 日期 | 问题描述 | 解决方案 |
|------|---------|---------|
| 2026-08-01 | Docker MySQL 容器删除后数据丢失 | 使用 `-v` 挂载本地目录持久化数据，如：`-v /Users/xhl/docker/mysql/data/mysql:/var/lib/mysql` |
| 2026-08-01 | Spring Boot 3.x 中 `javax.validation` 报错 | Spring Boot 3.x 使用 Jakarta EE，需将 `javax.validation` 改为 `jakarta.validation` |
| 2026-08-01 | Nacos Docker 镜像在 M1/M2 Mac 上报错 `no matching manifest for linux/arm64` | 使用 `--platform linux/amd64` 参数运行：`docker run --platform linux/amd64 ...` |
| 2026-08-01 | Spring Boot 2.4+ 启动报错 `spring.config.import=nacos:` | 在 application.yml 中添加：`spring.config.import: optional:nacos:gov-system.yml` |
| 2026-08-01 | MyBatis-Plus 报错 `@TableId can't more than one` | 联合主键表（如 role_menu、user_role）不能用 `@TableId`，改用 `@TableField` |
| 2026-08-01 | 多模块项目中 Bean 无法注入（如 RedisUtils） | 启动类添加 `@ComponentScan(basePackages = {"当前模块包", "common模块包"})` |
| 2026-08-01 | `@Valid` 参数校验注解不生效，返回业务异常而非校验提示 | `spring-boot-starter-validation` 在 core 模块标记为 `<optional>true</optional>`，不会传递依赖。需在使用模块（如 gov-system）的 pom.xml 中显式添加该依赖 |
