## 四、测试用例与结果

### 4.1 正向测试

#### 测试用例 1：登录获取 Token

**请求：**
```bash
curl -X POST http://localhost:8081/sysUser/login \
  -H "Content-Type: application/json" \
  -d '{"phone":"13900139000","password":"123456"}'
```

**响应：**
```json
{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "accessToken": "eyJhbGciOiJIUzM4NCJ9...",
        "userId": 2083874498985095170,
        "username": "13900139000",
        "nickname": "",
        "userType": 1
    },
    "success": true
}
```

**结果：** ✅ 通过

---

#### 测试用例 2：查询认证状态（未认证）

**请求：**
```bash
curl -X GET http://localhost:8081/sysUser/realNameStatus \
  -H "Authorization: Bearer <Token>"
```

**响应：**
```json
{
    "code": 200,
    "msg": "操作成功",
    "data": {
        "status": 0,
        "realName": "***",
        "idCard": "***"
    },
    "success": true
}
```

**结果：** ✅ 通过

**说明：**
- status = 0 表示未认证
- realName = "***" 表示未填写
- idCard = "***" 表示未填写

---

## 六、注意事项

### 6.1 安全说明

| 项目 | 说明 |
|------|------|
| Token 验证 | 每次请求都要验证 Token |
| 身份证号唯一 | 同一身份证号只能认证一个用户 |
| 数据脱敏 | 返回给前端的姓名和身份证号是脱敏的 |

### 6.2 使用说明

| 步骤 | 说明 |
|------|------|
| 1 | 用户登录获取 Token |
| 2 | 使用 Token 调用实名认证接口 |
| 3 | 传入真实姓名和身份证号 |
| 4 | 认证成功后，查询接口返回脱敏信息 |
