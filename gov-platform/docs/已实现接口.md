# 已实现接口记录

> 最后更新：2026-11-19
>
> 网关统一入口：`http://localhost:8080`，路径前缀 `/system` 对应 gov-system，`/item` 对应 gov-item
>
> 除标注「免认证」外，所有接口都需要在请求头带 `Authorization: Bearer {token}`

---

## 一、系统服务（gov-system）

### 1.1 认证与用户（/sysUser）

#### 免认证接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/sysUser/sendCode` | 发短信验证码，6位，5分钟有效 |
| POST | `/sysUser/register` | 手机号+密码+验证码注册 |
| POST | `/sysUser/login` | 手机号+密码登录，连错5次锁15分钟 |
| POST | `/sysUser/smsLogin` | 手机号+验证码登录，没注册过会自动注册 |
| POST | `/sysUser/adminLogin` | 管理端登录，用户名+密码，只能工作人员账号用 |
| POST | `/sysUser/resetPassword` | 找回密码，走手机验证码验证 |

#### 登录后接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/sysUser/info` | 查看当前登录用户的个人信息 |
| PUT | `/sysUser/info` | 修改昵称、头像、性别、邮箱 |
| POST | `/sysUser/changePassword` | 修改密码，需要验证旧密码 |
| POST | `/sysUser/realNameAuth` | 提交身份证号+姓名做实名认证 |
| GET | `/sysUser/realNameStatus` | 查看自己的实名认证状态 |

#### 管理员接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/sysUser/admin/page` | 用户分页列表，可按用户名/手机号/类型/状态筛 |
| GET | `/sysUser/admin/{userId}` | 查看某个用户的详细信息 |
| POST | `/sysUser/admin` | 新增用户 |
| PUT | `/sysUser/admin` | 修改用户信息 |
| DELETE | `/sysUser/admin/{userId}` | 删除用户（逻辑删除） |
| PUT | `/sysUser/admin/resetPassword/{userId}` | 把用户密码重置为 123456 |
| PUT | `/sysUser/admin/assignRoles/{userId}` | 给用户分配角色 |

## 二、事项服务（gov-item）

### 2.1 事项分类（/itemCategory）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/itemCategory/tree` | 查分类树形结构 |
| GET | `/itemCategory/list` | 根据父分类ID查子分类列表 |
| GET | `/itemCategory/{categoryId}` | 查分类详情 |
| POST | `/itemCategory` | 新增分类 |
| PUT | `/itemCategory` | 修改分类 |
| DELETE | `/itemCategory/{categoryId}` | 删除分类 |

---

### 2.2 事项信息（/itemInfo）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/itemInfo/list` | 事项分页列表，可按分类/名称/状态筛 |
| GET | `/itemInfo/{itemId}` | 查事项详情 |
| POST | `/itemInfo` | 新增事项（默认草稿状态） |
| PUT | `/itemInfo` | 修改事项（已发布的不能改，要先下线） |
| DELETE | `/itemInfo/{itemId}` | 删除事项（草稿/已下线才能删） |
| PUT | `/itemInfo/publish/{itemId}` | 发布事项（只有草稿能发布） |
| PUT | `/itemInfo/offline/{itemId}` | 下线事项（只有已发布能下线） |

事项状态流转：`草稿(0) → 已发布(1) → 已下线(2)`

---

### 2.3 事项收藏（/itemFavorite）

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/itemFavorite` | 收藏事项 |
| DELETE | `/itemFavorite` | 取消收藏 |
| GET | `/itemFavorite/check` | 查当前用户是否收藏了某个事项 |
| GET | `/itemFavorite/list` | 我的收藏列表（分页） |

---

### 2.4 表单模板（/itemFormTemplate）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/itemFormTemplate/item/{itemId}` | 查某个事项下的所有表单模板 |
| GET | `/itemFormTemplate/{templateId}` | 查模板详情 |
| GET | `/itemFormTemplate/active/{itemId}` | 获取事项当前启用的模板（前端渲染申请表单用） |
| POST | `/itemFormTemplate` | 新增模板 |
| PUT | `/itemFormTemplate` | 修改模板（已启用的不能改） |
| DELETE | `/itemFormTemplate/{templateId}` | 删除模板（已启用的不能删） |
| PUT | `/itemFormTemplate/enable/{templateId}` | 启用模板（同一事项下同时只能有一个启用） |
| PUT | `/itemFormTemplate/disable/{templateId}` | 禁用模板 |

---

### 2.5 材料模板（/itemMaterialTemplate）

| 方法 | 路径 | 说明 |

---

### 2.6 事项材料关联（/itemMaterialRelation）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/itemMaterialRelation/item/{itemId}` | 查某个事项需要提交的所有材料 |
| POST | `/itemMaterialRelation/set` | 批量设置事项所需材料（先清空再写入） |
| DELETE | `/itemMaterialRelation/{id}` | 删掉单条材料关联 |
| DELETE | `/itemMaterialRelation/item/{itemId}` | 清空某个事项的全部材料关联 |
